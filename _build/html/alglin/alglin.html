Álgebra Linear com SciPy#

O principal pacote Python para álgebra linear é o subpacote do SciPy scipy.linalg, que é construído sobre o NumPy. Vamos importar ambos os pacotes:

import numpy as np
import scipy.linalg as la

Arrays NumPy#

Vamos começar com uma rápida revisão dos Arrays NumPy. Podemos pensar em um array NumPy 1D como uma lista de números. Podemos pensar em um array NumPy 2D como uma matriz. E podemos pensar em um array 3D como um cubo de números. Quando selecionamos uma linha ou coluna de um array NumPy 2D, o resultado é um array NumPy 1D (chamado de fatia ou slice). Isso é diferente do MATLAB, onde, ao selecionar uma coluna de uma matriz, ela é retornada como um vetor coluna, que é uma matriz 2D do MATLAB.

Isso pode ficar um pouco confuso, então precisamos ficar atentos à forma (shape), tamanho (size) e dimensão dos nossos arrays NumPy.

Atributos do Array#

Crie um array NumPy 1D (unidimensional) e verifique suas dimensões, forma e tamanho.

a = np.array([1,3,-2,1])
print(a)

[ 1  3 -2  1]

Verifique o número de dimensões:

a.ndim

1

Verifique a forma do array:

a.shape

(4,)

A forma de um array é retornada como uma tupla Python. A saída na célula acima é uma tupla de comprimento 1. E verificamos o tamanho do array (ou seja, o número total de elementos no array):

a.size

4

Crie um array NumPy 2D (bidimensional) (ou seja, uma matriz):

M = np.array([[1,2],[3,7],[-1,5]])
print(M)

[[ 1  2]
 [ 3  7]
 [-1  5]]

Verifique o número de dimensões:

M.ndim

2

Verifique a forma do array:

M.shape

(3, 2)

Finalmente, verifique o número total de elementos no array:

M.size

6

Selecione uma linha ou coluna de um array NumPy 2D e obteremos um array 1D:

col = M[:,1]
print(col)

[2 7 5]

Verifique o número de dimensões da fatia:

col.ndim

1

Verifique a forma e o tamanho da fatia:

col.shape

(3,)

col.size

3

Quando selecionamos uma linha ou coluna de um array NumPy 2D, o resultado é um array NumPy 1D. No entanto, podemos querer selecionar uma coluna como um vetor coluna 2D. Isso exige que usemos o método reshape.

Por exemplo, crie um vetor coluna 2D a partir da fatia 1D selecionada da matriz M acima:

print(col)

[2 7 5]

column = col.reshape(3,1)
print(column)

[[2]
 [7]
 [5]]

Verifique as dimensões, forma e tamanho do array:

print('Dimensões:', column.ndim)
print('Forma:', column.shape)
print('Tamanho:', column.size)

Dimensões: 2
Forma: (3, 1)
Tamanho: 3

As variáveis col e column são tipos diferentes de objetos, embora contenham os «mesmos» dados.

print(col)

[2 7 5]

print('Dimensões:',col.ndim)
print('Forma:',col.shape)
print('Tamanho:',col.size)

Dimensões: 1
Forma: (3,)
Tamanho: 3

col2 = column.reshape(1,3)
print(col2)

[[2 7 5]]

Operações e Funções Matriciais#

Operações Aritméticas#

Lembre-se que as operações aritméticas de array +, -, /, * e ** são realizadas elemento a elemento em arrays NumPy. Vamos criar um array NumPy e fazer alguns cálculos:

M = np.array([[3,4],[-1,5]])
print(M)

[[ 3  4]
 [-1  5]]

M * M

array([[ 9, 16],
       [ 1, 25]])

Multiplicação de Matrizes#

Usamos o operador @ para fazer multiplicação de matrizes com arrays NumPy:

M @ M

array([[ 5, 32],
       [-8, 21]])

Vamos calcular \(2I + 3A - AB\) para

\[\begin{split} A = \begin{bmatrix} 1 & 3 \\\ -1 & 7 \end{bmatrix} \ \ \ \ B = \begin{bmatrix} 5 & 2 \\\ 1 & 2 \end{bmatrix} \end{split}\]

e \(I\) é a matriz identidade de tamanho 2:

A = np.array([[1,3],[-1,7]])
print(A)

[[ 1  3]
 [-1  7]]

B = np.array([[5,2],[1,2]])
print(B)

[[5 2]
 [1 2]]

I = np.eye(2)
print(I)

[[1. 0.]
 [0. 1.]]

2*I + 3*A - A@B

array([[-3.,  1.],
       [-5., 11.]])

Potências de Matrizes#

Não há um símbolo para potências de matrizes e, por isso, devemos importar a função matrix_power do subpacote numpy.linalg.

from numpy.linalg import matrix_power as mpow

M = np.array([[3,4],[-1,5]])
print(M)

[[ 3  4]
 [-1  5]]

mpow(M,2)

array([[ 5, 32],
       [-8, 21]])

mpow(M,5)

array([[-1525,  3236],
       [ -809,    93]])

Compare com o operador de multiplicação de matrizes:

M @ M @ M @ M @ M

array([[-1525,  3236],
       [ -809,    93]])

mpow(M,3)

array([[-17, 180],
       [-45,  73]])

M @ M @ M

array([[-17, 180],
       [-45,  73]])

Transposta#

Podemos obter a transposta com o atributo .T:

print(M)

[[ 3  4]
 [-1  5]]

print(M.T)

[[ 3 -1]
 [ 4  5]]

Note que \(M M^T\) é uma matriz simétrica:

M @ M.T

array([[25, 17],
       [17, 26]])

Inversa#

Podemos encontrar a inversa usando a função scipy.linalg.inv:

A = np.array([[1,2],[3,4]])
print(A)

[[1 2]
 [3 4]]

la.inv(A)

array([[-2. ,  1. ],
       [ 1.5, -0.5]])

Traço#

Podemos encontrar o traço de uma matriz usando a função numpy.trace:

np.trace(A)

np.int64(5)

Determinante#

Encontramos o determinante usando a função scipy.linalg.det:

A = np.array([[1,2],[3,4]])
print(A)

[[1 2]
 [3 4]]

la.det(A)

np.float64(-2.0)

Exemplos#

Polinômios Característicos e Teorema de Cayley-Hamilton#

O polinômio característico de uma matriz quadrada \(A\) 2x2 é

\[ p_A(\lambda) = \det(A - \lambda I) = \lambda^2 - \mathrm{tr}(A) \lambda + \mathrm{det}(A) \]

O Teorema de Cayley-Hamilton afirma que toda matriz quadrada satisfaz seu polinômio característico. Para uma matriz \(A\) de tamanho 2, isso significa que

\[ p_A(A) = A^2 - \mathrm{tr}(A) A + \mathrm{det}(A) I = 0 \]

Vamos verificar o Teorema de Cayley-Hamilton para algumas matrizes diferentes.

print(A)

[[1 2]
 [3 4]]

trace_A = np.trace(A)
det_A = la.det(A)
I = np.eye(2)
A @ A - trace_A * A + det_A * I

array([[0., 0.],
       [0., 0.]])

Vamos fazer isso novamente para algumas matrizes aleatórias:

N = np.random.randint(0,10,[2,2])
print(N)

[[2 3]
 [2 4]]

trace_N = np.trace(N)
det_N = la.det(N)
I = np.eye(2)
N @ N - trace_N * N + det_N * I

array([[-4.4408921e-16,  0.0000000e+00],
       [ 0.0000000e+00, -4.4408921e-16]])

Projeções#

A fórmula para projetar um vetor \(v\) em um vetor \(w\) é

\[ \mathrm{proj}_w(v) = \frac{v \cdot w}{w \cdot w} w \]

Vamos escrever uma função chamada proj que calcula a projeção de \(v\) em \(w\).

Para isso, note que o produto interto \(v \cdot w\) pode ser calculado como:

v = np.array([1,2,3])
w = np.array([1,1,1])
print(v*w)
print(np.sum(v*w))

[1 2 3]
6

def proj(v,w):
    '''Projeta o vetor v em w.'''
    v = np.array(v)
    w = np.array(w)
    return np.sum(v * w)/np.sum(w * w) * w   # ou (v @ w)/(w @ w) * w

proj([1,2,3],[1,1,1])

array([2., 2., 2.])
