Sistemas Lineares#

import numpy as np
import matplotlib.pyplot as plt
import scipy.linalg as la
%matplotlib inline

Sistemas Lineares#

Um sistema de equações lineares é um conjunto de equações lineares

(24)#\[\begin{align} a_{0,0}x_0 + a_{0,1}x_2 + \cdots + a_{0,n}x_n & = b_0 \\\ a_{1,0}x_0 + a_{1,1}x_2 + \cdots + a_{1,n}x_n & = b_1 \\\ & \vdots \\\ a_{m,0}x_0 + a_{m,1}x_2 + \cdots + a_{m,n}x_n & = b_m \\\ \end{align}\]

Em notação matricial, um sistema linear é \(A \mathbf{x}= \mathbf{b}\), onde

\[\begin{split} A = \begin{bmatrix} a_{0,0} & a_{0,1} & \cdots & a_{0,n} \\\ a_{1,0} & a_{1,1} & \cdots & a_{1,n} \\\ \vdots & & & \vdots \\\ a_{m,0} & a_{m,1} & \cdots & a_{m,n} \\\ \end{bmatrix} \ \ , \ \ \mathbf{x} = \begin{bmatrix} x_0 \\\ x_1 \\\ \vdots \\\ x_n \end{bmatrix} \ \ , \ \ \mathbf{b} = \begin{bmatrix} b_0 \\\ b_1 \\\ \vdots \\\ b_m \end{bmatrix} \end{split}\]

Eliminação Gaussiana#

O procedimento geral para resolver um sistema de equações lineares é chamado de eliminação gaussiana. A ideia é realizar operações elementares nas linhas para reduzir o sistema à sua forma escalonada e então resolvê-lo.

Operações Elementares nas Linhas#

As operações elementares nas linhas incluem:

  1. Somar \(k\) vezes a linha \(j\) à linha \(i\).

  2. Multiplicar a linha \(i\) pelo escalar \(k\).

  3. Trocar as linhas \(i\) e \(j\).

Cada uma das operações elementares nas linhas é o resultado da multiplicação por uma matriz elementar (à esquerda). Para somar \(k\) vezes a linha \(j\) à linha \(i\) em uma matriz \(A\), multiplicamos \(A\) pela matriz \(E\), onde \(E\) é igual à matriz identidade, exceto que o elemento \(i,j\) é \(E_{i,j} = k\). Por exemplo, se \(A\) é 3x3 e queremos somar 3 vezes a linha 2 à linha 0 (usando indexação baseada em 0), então

\[\begin{split} E_1 = \begin{bmatrix} 1 & 0 & 3 \\\ 0 & 1 & 0 \\\ 0 & 0 & 1 \end{bmatrix} \end{split}\]

Vamos verificar o cálculo:

A = np.array([[1,1,2],[-1,3,1],[0,5,2]])
print(A)

[[ 1  1  2]
 [-1  3  1]
 [ 0  5  2]]

E1 = np.array([[1,0,3],[0,1,0],[0,0,1]])
print(E1)

[[1 0 3]
 [0 1 0]
 [0 0 1]]

E1 @ A

array([[ 1, 16,  8],
       [-1,  3,  1],
       [ 0,  5,  2]])

Para multiplicar a linha \(i\) por \(k\) em uma matriz \(A\), multiplicamos \(A\) pela matriz \(E\), onde \(E\) é igual à matriz identidade, exceto que o elemento \(i,i\) é \(E_{i,i} = k\). Por exemplo, se \(A\) é 3x3 e queremos multiplicar a linha 1 por -2, então

\[\begin{split} E_2 = \begin{bmatrix} 1 & 0 & 0 \\\ 0 & -2 & 0 \\\ 0 & 0 & 1 \end{bmatrix} \end{split}\]

Vamos verificar o cálculo:

E2 = np.array([[1,0,0],[0,-2,0],[0,0,1]])
print(E2)

[[ 1  0  0]
 [ 0 -2  0]
 [ 0  0  1]]

E2 @ A

array([[ 1,  1,  2],
       [ 2, -6, -2],
       [ 0,  5,  2]])

Finalmente, para trocar a linha \(i\) e a linha \(j\) em uma matriz \(A\), multiplicamos \(A\) pela matriz \(E\), onde \(E\) é igual à matriz identidade, exceto que \(E_{i,i} = 0\), \(E_{j,j} = 0\), \(E_{i,j} = 1\) e \(E_{j,i} = 1\). Por exemplo, se \(A\) é 3x3 e queremos trocar a linha 1 e a linha 2, então

\[\begin{split} E_3 = \begin{bmatrix} 1 & 0 & 0 \\\ 0 & 0 & 1 \\\ 0 & 1 & 0 \end{bmatrix} \end{split}\]

Vamos verificar o cálculo:

E3 = np.array([[1,0,0],[0,0,1],[0,1,0]])
print(E3)

[[1 0 0]
 [0 0 1]
 [0 1 0]]

E3 @ A

array([[ 1,  1,  2],
       [ 0,  5,  2],
       [-1,  3,  1]])

Implementação#

Vamos escrever funções para implementar as operações elementares nas linhas. Primeiramente, vamos escrever uma função chamada add_row que recebe os parâmetros de entrada \(A\), \(k\), \(i\) e \(j\) e retorna o array NumPy resultante de somar \(k\) vezes a linha \(j\) à linha \(i\) na matriz \(A\). Se \(i=j\), vamos dizer que a função escala a linha \(i\) por \(k+1\), pois este seria o resultado de \(k\) vezes a linha \(i\) somada à linha \(i\).

def add_row(A,k,i,j):
    """Soma k vezes a linha j à linha i na matriz A."""
    n = A.shape[0]
    E = np.eye(n)
    if i == j:
        E[i,i] = k + 1
    else:
        E[i,j] = k
    return E @ A

Vamos testar nossa função:

M = np.array([[1,1],[3,2]])
print(M)

[[1 1]
 [3 2]]

add_row(M,2,0,1)

array([[7., 5.],
       [3., 2.]])

add_row(M,3,1,1)

array([[ 1.,  1.],
       [12.,  8.]])

Vamos escrever uma função chamada scale_row que recebe 3 parâmetros de entrada \(A\), \(k\) e \(i\) e retorna a matriz que resulta da multiplicação da linha \(i\) por \(k\) na matriz \(A\).

def scale_row(A,k,i):
    """Multiplica a linha i por k na matriz A."""
    n = A.shape[0]
    E = np.eye(n)
    E[i,i] = k
    return E @ A

M = np.array([[3,1],[-2,7]])
print(M)

[[ 3  1]
 [-2  7]]

scale_row(M,3,1)

array([[ 3.,  1.],
       [-6., 21.]])

A = np.array([[1,1,1],[1,-1,0]])
print(A)

[[ 1  1  1]
 [ 1 -1  0]]

scale_row(A,5,1)

array([[ 1.,  1.,  1.],
       [ 5., -5.,  0.]])

Vamos escrever uma função chamada switch_rows que recebe 3 parâmetros de entrada \(A\), \(i\) e \(j\) e retorna a matriz que resulta da troca das linhas \(i\) e \(j\) na matriz \(A\).

def switch_rows(A,i,j):
    """Troca as linhas i e j na matriz A."""
    n = A.shape[0]
    E = np.eye(n)
    E[i,i] = 0
    E[j,j] = 0
    E[i,j] = 1
    E[j,i] = 1
    return E @ A

A = np.array([[1,1,1],[1,-1,0]])
print(A)

[[ 1  1  1]
 [ 1 -1  0]]

switch_rows(A,0,1)

array([[ 1., -1.,  0.],
       [ 1.,  1.,  1.]])

Resolver um Sistema#

Vamos usar nossas funções para realizar a eliminação gaussiana e resolver um sistema de equações lineares \(A \mathbf{x} = \mathbf{b}\).

A = np.array([[6,15,1],[8,7,12],[2,7,8]])

M = np.hstack([A,b])

scipy.linalg.solve#

Estamos interessados principalmente em sistemas lineares \(A \mathbf{x} = \mathbf{b}\) onde há uma solução única \(\mathbf{x}\). Este é o caso quando \(A\) é uma matriz quadrada (\(m=n\)) e \(\mathrm{det}(A) \not= 0\). Para resolver tal sistema, podemos usar a função scipy.linalg.solve.

A função retorna uma solução do sistema de equações \(A \mathbf{x} = \mathbf{b}\). Por exemplo:

A = np.array([[1,1],[1,-1]])
print(A)

[[ 1  1]
 [ 1 -1]]

b1 = np.array([2,0])
print(b1)

[2 0]

E resolvemos:

x1 = la.solve(A,b1)
print(x1)

[1. 1.]

Note que a saída \(\mathbf{x}\) é retornada como um array NumPy 1D quando o vetor \(\mathbf{b}\) (o lado direito) é inserido como um array NumPy 1D. Se inserirmos \(\mathbf{b}\) como um array NumPy 2D, então a saída é um array NumPy 2D. Por exemplo:

A = np.array([[1,1],[1,-1]])
b2 = np.array([2,0]).reshape(2,1)
x2 = la.solve(A,b2)
print(x2)

[[1.]
 [1.]]

Finalmente, se o lado direito \(\mathbf{b}\) é uma matriz, então a saída é uma matriz do mesmo tamanho. É a solução de \(A \mathbf{X} = \mathbf{B}\) quando \(\mathbf{B}\) é uma matriz. Por exemplo:

A = np.array([[1,1],[1,-1]])
B = np.array([[2,2],[0,1]])
X = la.solve(A,B)
print(X)

[[1.  1.5]
 [1.  0.5]]

Ainv = la.solve(A,np.eye(2))
print(Ainv)
print(Ainv @ A)

[[ 0.5  0.5]
 [ 0.5 -0.5]]
[[1. 0.]
 [0. 1.]]

Exemplo Simples#

Vamos calcular a solução do sistema de equações

(25)#\[\begin{align} 2x + y &= 1 \\\ x + y &= -1 \end{align}\]

Crie a matriz de coeficientes:

A = np.array([[2,1],[1,1]])
print(A)

[[2 1]
 [1 1]]

E o vetor \(\mathbf{b}\):

b = np.array([1,-1]).reshape(2,1)
print(b)

[[ 1]
 [-1]]

E resolvemos:

x = la.solve(A,b)
print(x)

[[ 2.]
 [-3.]]

Podemos verificar a solução calculando a inversa de \(A\):

Ainv = la.inv(A)
print(Ainv)

[[ 1. -1.]
 [-1.  2.]]

E multiplicamos \(A^{-1} \mathbf{b}\) para resolver para \(\mathbf{x}\):

x = Ainv @ b
print(x)

[[ 2.]
 [-3.]]

Obtemos o mesmo resultado. Sucesso!

Inversa ou Resolver#

É uma má ideia usar a inversa \(A^{-1}\) para resolver \(A \mathbf{x} = \mathbf{b}\) se \(A\) for grande. É muito caro computacionalmente. Vamos criar uma matriz aleatória grande \(A\) e um vetor \(\mathbf{b}\) e calcular a solução \(\mathbf{x}\) de 2 maneiras:

N = 1000
A = np.random.rand(N,N)
b = np.random.rand(N,1)

Verifique os primeiros elementos de \(A\):

A[:3,:3]

array([[0.34050481, 0.59461987, 0.8826225 ],
       [0.29269095, 0.15662709, 0.16884694],
       [0.65742104, 0.08224234, 0.7803437 ]])

E para \(\mathbf{b}\):

b[:4,:]

array([[0.93601372],
       [0.2296962 ],
       [0.61763665],
       [0.11956213]])

Agora comparamos a velocidade de scipy.linalg.solve com scipy.linalg.inv:

%%timeit
x = la.solve(A,b)

The slowest run took 31.26 times longer than the fastest. This could mean that an intermediate result is being cached.
327 ms ± 244 ms per loop (mean ± std. dev. of 7 runs, 1 loop each)

%%timeit
x = la.inv(A) @ b

34.1 ms ± 5.27 ms per loop (mean ± std. dev. of 7 runs, 10 loops each)

Resolver com scipy.linalg.solve é muito mais rápido!
