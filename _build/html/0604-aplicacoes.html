Sistema Massa-Mola-Amortecedor#

Um sistema massa-mola-amortecedor é uma equação de segunda ordem com coeficientes constantes:

\[ my'' + cy' + ky = F(t) \]

onde \(m > 0, c \geq 0, k \geq 0\), e \(F(t)\) é a função de força externa. Escreva a equação como um sistema de primeira ordem 2-dimensional introduzindo novas variáveis \(u_0 = y\) e \(u_1 = y'\):

\begin{align} u’_0 &= u_1 \
u’_1 &= (F(t)-ku_0-cu_1)/m \end{align}

Escreva uma função chamada mass_spring_damper que receba os parâmetros de entrada m, c, k, F, u0 e t onde

  • m, c, k são coeficientes do sistema

  • F é a função de força externa \(F(t)\)

  • u0 é o vetor de condições iniciais u0 = [y(0), y'(0)]

  • t é um array NumPy 1D

A função retorna um array y de valores que aproximam a solução \(y(t)\) nos valores de \(t\) dados por t.

def mass_spring_damper(m,c,k,F,u0,t):

    def f(u,t):
        dudt = np.zeros(2)
        dudt[0] = u[1]
        dudt[1] = (F(t) - k*u[0] - c*u[1])/m
        return dudt

    U = spi.odeint(f,u0,t)
    y = U[:,0]
    return y

Se \(m=1\), \(c=0\), \(k=1\), \(f(t)=0\), \(y(0)=0\), \(y'(0)=1\), então a equação é

\[ y'' + y = 0 \]

para \(y(0)=0\), \(y'(0)=1\) e a solução é

\[ y=\sin(t) \]
m = 1; c = 0; k = 1;
F = lambda t: 0
t = np.linspace(0,4*np.pi,100)
u0 = [0,1]
y = mass_spring_damper(m,c,k,F,u0,t)
plt.plot(t,y,t,np.sin(t),'r.'), plt.grid(True)
plt.show()

A ressonância ocorre quando não há amortecimento \(c=0\) e a frequência da força externa é igual à frequência natural \(\omega_n = \sqrt{k/m}\), ou seja \(F(t)=\sin \left(\sqrt{\frac{k}{m}} t\right) \).

m = 1; c = 0; k = 10;
F = lambda t: np.sin((k/m)**0.5*t)
t = np.linspace(0,50,1000)
u0 = [0,0]
y = mass_spring_damper(m,c,k,F,u0,t)
plt.plot(t,y), plt.grid(True)
plt.show()

O batimento descreve o comportamento de um sistema não amortecido \(c=0\) quando a frequência da força externa está próxima, mas não é igual à frequência natural \(\omega_n = \sqrt{k/m}\).

m = 1; c = 0; k = 10;
F = lambda t: np.sin(3*t)
t = np.linspace(0,100,1000)
u0 = [0,0]
y = mass_spring_damper(m,c,k,F,u0,t)
plt.plot(t,y), plt.grid(True)
plt.show()

Em um sistema amortecido \(c \not= 0\), não pode haver ressonância, no entanto, existe uma frequência de força externa que produz a maior amplitude de estado estacionário. Essa frequência é chamada de frequência natural amortecida (ou ressonância prática).

m = 1; c = 2; k = 10;
F = lambda t: np.sin(2.7*t)
t = np.linspace(0,15,200)
u0 = [0,0]
y = mass_spring_damper(m,c,k,F,u0,t)
plt.plot(t,y), plt.grid(True)
plt.show()

Oscilador de Van der Pol#

A equação do oscilador de Van der Pol é dada por

\[ x'' - \mu(1 - x^2)x' + x = 0 \]

Escreva uma função chamada van_der_pol que receba os parâmetros mu, u0 e t e retorne um array NumPy 2D de tamanho (len(t),2) com valores de \(x\) na primeira coluna e valores de \(x'\) na segunda coluna para a solução com valores iniciais u0 = [x(0),x'(0)].

def van_der_pol(mu,u0,t):

    def f(u,t):
        dudt = np.zeros(2)
        dudt[0] = u[1]
        dudt[1] = mu*(1 - u[0]**2)*u[1] - u[0]
        return dudt

    U = spi.odeint(f,u0,t)
    x = U[:,0]
    dxdt = U[:,1]
    return np.column_stack((x,dxdt))

Plote \(x\) versus \(x'\) para a solução com \(\mu = 1\), \(x(0) = 1\) e \(x'(0)=4\).

U = van_der_pol(1,[1,6],np.linspace(0,100,2500))
plt.plot(U[:,0],U[:,1]), plt.grid(True)
plt.show()

Plote \(x\) versus \(x'\) para \(x(0) = 1\) e \(x'(0)=v_0\) para cada valor \(v_0 = 1,2,3,4,5,6\) e \(\mu=1\).

for v0 in [1,2,3,4,5,6]:
    U = van_der_pol(1,[1,v0],np.linspace(0,10,500))
    plt.plot(U[:,0],U[:,1])
plt.title("Equação de Van der Pol")
plt.grid(True), plt.legend(['$v_0=1$','$v_0=2$','$v_0=3$','$v_0=4$','$v_0=5$','$v_0=6$'])
plt.show()

Plote \(x\) versus \(x'\) para \(x(0) = 1\) e \(x'(0)=4\) para cada valor \(\mu = 0.2,0.5,1,2,3,4\).

for mu in [0.2,0.5,1,2,3,4]:
    U = van_der_pol(mu,[1,4],np.linspace(0,10,500))
    plt.plot(U[:,0],U[:,1])
plt.title("Equação de Van der Pol")
plt.grid(True), plt.legend(['$\mu=0.2$','$\mu=0.5$','$\mu=1$','$\mu=2$','$\mu=3$','$\mu=4$'])
plt.show()

Órbitas Planetárias#

Dado um objeto com massa \(M\), a magnitude da força da gravidade que ele exerce sobre outro objeto com massa \(m\) é

\[ F = \frac{GMm}{d^2} \]

onde \(d\) é a distância entre os objetos. Vamos considerar a trajetória de um planeta de massa \(m\) enquanto ele orbita uma estrela de massa \(M\) (fixa no espaço). Vamos usar as seguintes unidades:

  • massa solar (múltiplos da massa do Sol da Terra)

  • anos

  • unidades astronômicas (aproximadamente a distância da Terra ao Sol)

Com essas unidades, a constante gravitacional \(G\) é \(4 \pi^2\).

Seja \(\mathbf{p} = (x,y)\) a posição do planeta em órbita com a estrela fixa na origem \((0,0)\), e seja \(m_P\) a massa do planeta e \(m_S\) a massa da estrela. Começando com a Segunda Lei de Newton, temos

\[ m_P \frac{d^2 \mathbf{p}}{dt^2} = \mathbf{F} \]

onde \(\mathbf{F}\) é o vetor da força total atuando no planeta (que neste caso é apenas devido à gravidade). A lei da gravitação universal de Newton afirma

\[ \mathbf{F} = - \frac{G m_S m_P}{ || \mathbf{p} ||^2 } \frac{\mathbf{p}}{ || \mathbf{p} || } \]

onde \(|| \mathbf{p} || = \sqrt{x^2 + y^2}\) é a distância entre a estrela e o planeta, e \(-\mathbf{p} / || \mathbf{p} ||\) é o vetor unitário que aponta na direção do planeta para a estrela.

Juntando essas equações, obtemos um sistema bidimensional de equações diferenciais de segunda ordem

\begin{align} \frac{d^2 x}{dt^2} &= - \frac{G m_S x }{ (x^2 + y^2)^{3/2} } \
\frac{d^2 y}{dt^2} &= - \frac{G m_S y }{ (x^2 + y^2)^{3/2} } \end{align}

Escreva o sistema como um sistema de primeira ordem introduzindo novas variáveis: \(u_0 = x\), \(u_1 = x'\), \(u_2 = y\) e \(u_3 = y'\). O sistema se torna

\begin{align} u_0” &= u_1 \
u_1” &= - \frac{G m_S u_0 }{ (u_0^2 + u_2^2)^{3/2} } \
u_2” &= u_3 \
u_3” &= - \frac{G m_S u_2 }{ (u_0^2 + u_2^2)^{3/2} } \end{align}

Plote a órbita para \(m_S = 1\) com as condições iniciais \(x(0) = 1, x'(0) = 0, y(0) = 0, y'(0) = 7\).

G = 4*np.pi**2; mS = 1;

def f(u,t):
    dudt = np.zeros(4)
    dudt[0] = u[1]
    dudt[1] = -G*mS*u[0]/(u[0]**2 + u[2]**2)**(3/2)
    dudt[2] = u[3]
    dudt[3] = -G*mS*u[2]/(u[0]**2 + u[2]**2)**(3/2)
    return dudt

u0 = [1,0,0,7]
t = np.linspace(0,4,2000)
U = spi.odeint(f,u0,t)
plt.plot(U[:,0],U[:,2],0,0,'r*')
plt.axis('equal'), plt.grid(True)
plt.show()

Problema dos 3 Corpos de Euler#

O problema dos 3 corpos de Euler é uma versão simplificada (e, admitidamente, fisicamente impossível) do problema geral dos 3 corpos. O problema de Euler considera duas estrelas fixas no espaço e um planeta orbitando as estrelas em 2 dimensões. Vamos derivar as equações de movimento do planeta e, em seguida, plotar as trajetórias usando o solucionador de EDOs do SciPy, odeint.

Use as seguintes unidades:

  • massa solar (múltiplos da massa do Sol da Terra)

  • anos

  • unidades astronômicas (UA) (aproximadamente a distância da Terra ao Sol)

Com essas unidades, a constante gravitacional é \(G = 4 \pi^2\). Introduza variáveis para o planeta e as estrelas:

  • \(m_{S_1}\) - massa da estrela 1

  • \(m_{S_2}\) - massa da estrela 2

  • \(m_P\) - massa do planeta

  • \(x_{S_1}\) - posição \(x\) (fixa) da estrela 1

  • \(y_{S_1}\) - posição \(y\) (fixa) da estrela 1

  • \(x_{S_2}\) - posição \(x\) (fixa) da estrela 2

  • \(y_{S_2}\) - posição \(y\) (fixa) da estrela 2

  • \(x_P\) - posição \(x\) do planeta

  • \(y_P\) - posição \(y\) do planeta

  • \(\mathbf{p} = (x_P,y_P)\) - vetor posição do planeta

Seja \(\mathbf{F_1}\) a força da gravidade da estrela 1 atuando no planeta, e seja \(\mathbf{F_2}\) a força da gravidade da estrela 2 atuando no planeta. A Lei da Gravitação Universal de Newton afirma:

\[ \mathbf{F_1} = - \frac{ G m_P m_{S_1} }{ || \mathbf{d_1} ||^2} \frac{ \mathbf{d_1} }{ || \mathbf{d_1} || } \]
\[ \mathbf{F_2} = - \frac{ G m_P m_{S_2} }{ || \mathbf{d_2} ||^2} \frac{ \mathbf{d_2} }{ || \mathbf{d_2} || } \]

onde \(\mathbf{d_1} = (x_P-x_{S_1},y_P-y_{S_1})\) é o vetor da estrela 1 para o planeta, e \(\mathbf{d_2} = (x_P-x_{S_2},y_P-y_{S_2})\) é o vetor da estrela 2 para o planeta.

A Segunda Lei do Movimento de Newton afirma:

\[ \frac{ d^2 \mathbf{x} }{ dt^2 } = \mathbf{F}_1 + \mathbf{F}_2 \]

e isso nos leva ao sistema de EDOs de segunda ordem que governam o movimento do planeta:

\[ \frac{d^2 x_P}{dt^2} = - \frac{ G m_{S_1} (x_P - x_{S_1}) }{ || \mathbf{d_1} ||^3} - \frac{ G m_{S_2} (x_P - x_{S_2}) }{ || \mathbf{d_2} ||^3} \]
\[ \frac{d^2 y_P}{dt^2} = - \frac{ G m_{S_1} (y_P - y_{S_1}) }{ || \mathbf{d_1} ||^3} - \frac{ G m_{S_2} (y_P - y_{S_2}) }{ || \mathbf{d_2} ||^3} \]

Para plotar as trajetórias do planeta usando odeint, primeiro precisamos escrever o sistema como um sistema de primeira ordem. Introduza novas variáveis \(u_1 = x_P\), \(u_2 = x_P'\), \(u_3 = y_P\) e \(u_4 = y_P'\) e escreva

\begin{align} u_1” &= u_2 \
u_2” &= - \frac{ G m_{S_1} (u_1 - x_{S_1}) }{ || \mathbf{d_1} ||^3} - \frac{ G m_{S_2} (u_1 - x_{S_2}) }{ || \mathbf{d_2} ||^3} \
u_3” &= u_4 \
u_4” &= - \frac{ G m_{S_1} (u_3 - y_{S_1}) }{ || \mathbf{d_1} ||^3} - \frac{ G m_{S_2} (u_3 - y_{S_2}) }{ || \mathbf{d_2} ||^3} \end{align}

onde \(\mathbf{d_1} = (u_1-x_{S_1},u_3-y_{S_1})\) e \(\mathbf{d_2} = (u_1-x_{S_2},u_3-y_{S_2})\).

G = 4*np.pi**2 # Gravitational constant
S1 = [-2,0] # Coordinates of Star 1
S2 = [2,0] # Coordinates of Star 2
M1 = 2 # Mass of Star 1 (in solar mass)
M2 = 1 # Mass of Star 2 (in solar mass)

def f(u,t):
    d1 = np.linalg.norm([u[0] - S1[0],u[2] - S1[1]])
    d2 = np.linalg.norm([u[0] - S2[0],u[2] - S2[1]])
    dudt = [0,0,0,0]
    dudt[0] = u[1]
    dudt[1] = -G*M1*(u[0] - S1[0])/d1**3 - G*M2*(u[0] - S2[0])/d2**3
    dudt[2] = u[3]
    dudt[3] = -G*M1*(u[2] - S1[1])/d1**3 - G*M2*(u[2] - S2[1])/d2**3
    return dudt

u0 = [0,5,3,0] # Initial conditions of the planet: [xposition,xvelocity,yposition,yvelocity]
t = np.linspace(0,30,2000) # Array of time values (in years)
u = spi.odeint(f,u0,t) # Solve system: u = [xposition,xvelocity,yposition,yvelocity]

plt.plot(u[:,0],u[:,2]) # Plot trajectory of the planet
plt.plot(S1[0],S1[1],'ro',markersize=5*M1) # Plot Star 1 as a red star
plt.plot(S2[0],S2[1],'ro',markersize=5*M2) # Plot Star 2 as a red star
plt.axis('equal')
plt.show()

Vamos colocar o código acima em uma função que podemos chamar com diferentes condições iniciais para ver que tipos de órbitas podemos criar!

def euler3body(S1,S2,M1,M2,u0,tf,numpoints=1000):

    # Define the vector function on the right side of the system of the equations
    def f(u,t):
        d1 = np.linalg.norm([u[0]-S1[0],u[2]-S1[1]])
        d2 = np.linalg.norm([u[0]-S2[0],u[2]-S2[1]])
        dudt = [0,0,0,0]
        dudt[0] = u[1]
        dudt[1] = -G*M1*(u[0]-S1[0])/d1**3 - G*M2*(u[0]-S2[0])/d2**3
        dudt[2] = u[3]
        dudt[3] = -G*M1*(u[2]-S1[1])/d1**3 - G*M2*(u[2]-S2[1])/d2**3
        return dudt

    t = np.linspace(0,tf,numpoints) # Array of time values (in years)
    u = spi.odeint(f,u0,t) # Solve system: u = [xposition,xvelocity,yposition,yvelocity]

    plt.plot(u[:,0],u[:,2]) # Plot trajectory of the planet
    plt.plot(S1[0],S1[1],'ro',markersize=5*M1) # Plot Star 1 as a red star
    plt.plot(S2[0],S2[1],'ro',markersize=5*M2) # Plot Star 2 as a red star
    plt.axis('equal')
    plt.show()

euler3body([-1,0],[1,0],2,1,[0,5,3,0],30)

euler3body([-1,1],[1,-1],2,1,[0,10,0,5],30)

euler3body([-2,0],[2,0],1,1,[0,0,0,5],5)

euler3body([-2,0],[2,0],1.5,2.5,[0,4.8,3,0],20)

euler3body([0,10],[0,-10],4.9,4.9,[0,np.pi,0,np.pi],100)
