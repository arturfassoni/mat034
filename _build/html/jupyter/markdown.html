Markdown#

Markdown é uma linguagem de marcação simples de texto para HTML escrita em texto puro. O Jupyter Notebook reconhece markdown e renderiza o código markdown como HTML. Veja Markdown (por John Gruber) e Ajuda do GitHub Markdown para mais informações.

Texto#

Saída

Sintaxe

ênfase

*ênfase*

negrito

**negrito**

código

`código`

Links#

Tabelas#

Crie uma tabela separando as entradas por caracteres de barra vertical |:

| Operador Python | Descrição  |
| :---: | :---: |
| `+` | adição |
| `-` | subtração |
| `*` | multiplicação |
| `/` | divisão |
| `**` | potência |

A sintaxe :---: especifica o alinhamento (centralizado neste caso) das colunas. Veja mais sobre o markdown com sabor do GitHub (GitHub flavoured markdown).
