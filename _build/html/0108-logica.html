Lógica#

Valores Booleanos#

O tipo booleano tem apenas dois valores: True e False. Vamos atribuir um valor booleano a uma variável e verificar o tipo usando a função embutida type():

python_is_fun = True
print(python_is_fun)

type(python_is_fun)

python_is_fun = 1+2j
type(python_is_fun)

Vamos atribuir o valor False a uma variável e verificar novamente o tipo:

math_is_scary = False
print(math_is_scary)

type(math_is_scary)

Operadores de Comparação#

Operadores de comparação produzem valores Booleanos como saída. Por exemplo, se tivermos variáveis x e y com valores numéricos, podemos avaliar a expressão x < y e o resultado é um valor booleano, True ou False.

Descrição

<

estritamente menor que

<=

menor que ou igual a

>

estritamente maior que

>=

maior que ou igual a

==

igual a

Por exemplo:

1 == 2

1 < 2

2 == 2

3 != 3.14159

20.00000001 >= 20

Operadores Booleanos#

Combinamos expressões lógicas usando os operadores booleanos and, or e not.

Operador Booleano

Descrição

A and B

retorna True se tanto A quanto B forem True

A or B

retorna True se A ou B for True

not A

retorna True se A for False

Por exemplo:

(1 < 2) and (3 != 5)

(1 < 2) and (3 < 1)

(1 < 2) or (3 < 1)

not (1000 <= 999)

Declarações if#

Uma declaração if consiste em um ou mais blocos de código, de modo que apenas um bloco é executado dependendo das expressões lógicas.

Por exemplo, determine se as raízes da equação polinomial \(ax^2 + bx + c = 0\) são reais, repetidas ou complexas usando a fórmula de Bhaskara

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]
a = 1
b = -4
c = 1
discriminant = b**2 - 4*a*c
if discriminant > 0:
    print("Discriminant =", discriminant)
    print("Roots are real and distinct.")
elif discriminant < 0: # elif=else if="senão, então se"
    print("Discriminant =", discriminant)
    print("Roots are complex.")
else: #else = "senão"
    print("Discriminant =", discriminant)
    print("Roots are real and repeated.")

Os principais pontos a serem observados são:

  1. Comece com a palavra-chave if.

  2. Escreva uma expressão lógica (que retorne True ou False).

  3. Termine a linha com dois pontos :.

  4. Indente o bloco com 4 espaços após a declaração if.

  5. Inclua as declarações elif e else, se necessário.

  6. Apenas um dos blocos if, elif e else é executado.

  7. O bloco que segue uma declaração else será executado apenas se todas as outras expressões lógicas anteriores forem False.

Exemplos#

Matriz Invertível#

Represente uma matriz quadrada 2 por 2 como uma lista de listas. Por exemplo, represente a matriz

\[\begin{split} \begin{bmatrix} 2 & -1 \\\ 5 & 7 \end{bmatrix} \end{split}\]

como a lista de listas [[2,-1],[5,7]].

Escreva uma função chamada invertible que receba um parâmetro de entrada M, uma lista de listas representando uma matriz 2 por 2, e retorne True se a matriz M for invertível e False caso contrário.

def invertible(M):
    "Determine if the matrix M = [[a,b],[c,d]] is invertible."
    determinant = M[0][0] * M[1][1] - M[0][1] * M[1][0]
    if determinant != 0:
        return True
    else:
        return False

Vamos testar nossa função:

invertible([[1,2],[3,4]])

invertible([[1,1],[3,3]])

Concavidade de um Polinômio#

Escreva uma função chamada concave_up que receba os parâmetros de entrada p e a, onde p é uma lista que representa um polinômio \(p(x)\) e a é um número, e retorne True se a função \(p(x)\) tiver concavidade para cima em \(x=a\) (ou seja, sua segunda derivada é positiva em \(x=a\), \(p''(a) > 0\)).

Usaremos o teste da segunda derivada para polinômios. Em particular, se tivermos um polinômio de grau \(n\)

\[ p(x) = c_0 + c_1 x + c_2 x^2 + \cdots + c_n x^n \]

então a segunda derivada de \(p(x)\) em \(x=a\) é a soma

\[ p''(a) = 2(1) c_2 + 3(2)c_3 a + 4(3)c_4 a^2 + \cdots + n(n-1)c_n a^{n-2} \]
def concave_up(p,a):
    "Determine if the polynomial p(x) is concave up at x=a."
    degree = len(p) - 1
    if degree < 2:
        return False
    else:
        # Compute the second derivative p''(a)
        DDp_a = sum([k*(k-1)*p[k]*a**(k-2) for k in range(2,degree + 1)])
        if DDp_a > 0:
            return True
        else:
            return False

Vamos testar nossa função em \(p(x) = 1 + x - x^3\) em \(x=2\). Como \(p''(x) = -6x\) e \(p''(2) = -12 < 0\), o polinômio tem concavidade para baixo em \(x=2\).

p = [1,1,0,-1]
a = 2
concavity = concave_up(p,a)
print(concavity)

Exercícios#

Exercício 1. O discriminante de um polinômio cúbico \(p(x) = ax^3 + bx^2 + cx + d\) é

\[ \Delta = b^2c^2 - 4ac^3 - 4b^3d - 27a^2d^2 + 18abcd \]

O discriminante nos dá informações sobre as raízes do polinômio \(p(x)\):

  • se \(\Delta > 0\), então \(p(x)\) tem 3 raízes reais distintas

  • se \(\Delta < 0\), então \(p(x)\) tem 2 raízes complexas distintas e 1 raiz real

  • se \(\Delta = 0\), então \(p(x)\) tem pelo menos 2 raízes (reais ou complexas) que são iguais

Represente um polinômio cúbico \(p(x) = ax^3 + bx^2 + cx + d\) como uma lista [d,c,b,a] de números. (Note que a ordem dos coeficientes é de grau crescente.) Por exemplo, o polinômio \(p(x) = x^3 - x + 1\) é [1,-1,0,1].

Escreva uma função chamada cubic_roots que receba um parâmetro de entrada p, uma lista de comprimento 4 representando um polinômio cúbico, e retorne True se \(p(x)\) tiver 3 raízes reais distintas e False caso contrário.

Exercício 2. Represente uma matriz quadrada 2 por 2 como uma lista de listas. Por exemplo, represente a matriz

\[\begin{split} \begin{bmatrix} 2 & -1 \\\ 5 & 7 \end{bmatrix} \end{split}\]

como a lista de listas [[2,-1],[5,7]]. Escreva uma função chamada inverse_a que receba um parâmetro de entrada a e retorne uma lista de listas representando a inversa da matriz

\[\begin{split} \begin{bmatrix} 1 & a \\\ a & -1 \end{bmatrix} \end{split}\]

Exercício 3. Escreva uma função chamada real_eigenvalues que receba um parâmetro de entrada M, uma lista de listas representando uma matriz 2 por 2 (como no exercício anterior), e retorne True se os autovalores da matriz M forem números reais e False caso contrário.
