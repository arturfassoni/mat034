Funções#

Uma função recebe parâmetros de entrada, executa uma série de cálculos com essas entradas e, em seguida, retorna um valor de saída final. As funções nos dão uma maneira eficiente de salvar e reutilizar um bloco de código repetidamente com diferentes valores de entrada. Existem funções embutidas na biblioteca padrão do Python e podemos definir nossas próprias funções.

A biblioteca padrão do Python tem uma coleção de funções embutidas prontas para usarmos. Já vimos algumas dessas funções em seções anteriores, como type(), print() e sum(). A seguir, uma lista das funções embutidas que usaremos com mais frequência:

reversed_random = list(reversed(random))

squares = [n**2 for n in range(0,6)]

Isso ocorre porque essas funções retornam objetos iteradores (semelhantes a objetos range) que só produzem valores quando explicitamente instruídos a fazê-lo.

Definindo Funções#

Vamos começar com um exemplo simples. Defina uma função que retorna a média de uma sequência de números:

def average(x):
    "Compute the average of the values in the sequence x."
    sum_x = sum(x)
    length_x = len(x)
    return sum_x / length_x

x=[1,2,3,4,5]
average(x)

Os principais pontos a serem observados são:

  1. Comece a definição da função com a palavra-chave def.

  2. Siga def com o nome da função.

  3. Siga o nome da função com a lista de parâmetros de entrada separados por vírgulas e dentro de parênteses.

  4. Termine a declaração def com dois pontos :.

  5. Indente o corpo da função com 4 espaços.

  6. Use a palavra-chave return para especificar a saída da função (mas nem sempre é necessário).

  7. A segunda linha é uma string de documentação (docstring, entre aspas » … «) que descreve a função.

Em Python, blocos de código são definidos usando indentação. Isso significa que linhas de código com a mesma quantidade de indentação são consideradas um bloco. No exemplo acima, as quatro linhas indentadas abaixo da declaração def formam o corpo da função.

Observe que não há saída quando executamos a célula que contém a definição da função. Isso ocorre porque apenas definimos a função e ela está esperando que a usemos! Precisamos chamar a função com valores para os parâmetros de entrada, e então a função irá calcular e retornar o valor de saída.

Vamos testar nossa função:

average([1,2,3,4])

average(range(1,10))

A função retorna o valor esperado. Sucesso!

Strings de Documentação (Docstrings)#

A primeira linha após a declaração def em uma definição de função deve ser uma string de documentação (ou docstring). Uma docstring é um texto (entre aspas duplas " ... " ou aspas triplas ''' ... ''') que descreve sua função. Use aspas triplas para uma docstring de várias linhas. Veja a documentação do Python para todas as convenções relacionadas a strings de documentação.

Um recurso útil do notebook Jupyter é o operador de ponto de interrogação ?. Ele exibirá a docstring de uma função. Tenha isso em mente ao escrever suas docstrings: outras pessoas lerão sua docstring para aprender a usar sua função.

Por exemplo, use o ponto de interrogação ? para ver a documentação da função embutida sum():

sum?

Argumentos de Palavra-chave (Keyword Arguments)#

Quando definimos funções, listamos os parâmetros de entrada. Estes são chamados de parâmetros posicionais (ou argumentos posicionais) porque a posição na declaração def determina qual parâmetro é qual.

def poly(x,y):
    "Compute x + y**2."
    return x + y**2

poly(1,2)

poly(2,1)

Um argumento de palavra-chave nos permite inserir valores padrão para alguns parâmetros e podemos chamá-los pelo nome, e a ordem não importa.

Por exemplo, vamos escrever uma função chamada psum que recebe os números x e y e o argumento de palavra-chave p (com valor padrão p=1) e retorna a soma das potências

\[ x^p + y^p \]
def psum(x,y,p=2):
    return x**p + y**p

psum(1,2)

psum(1,2,p=1)

psum(2,3,p=3)

Nesta função, x e y são argumentos posicionais e p é um argumento de palavra-chave.

def psum2(x,y,p=2,q=3):
    "uma função com dois parâmetros"
    return x**p + y**q

psum2(1,2,q=-1)

Comentários#

Comentários em um programa Python são descrições em texto simples do código Python que explicam o código para o leitor. O Python ignorará as linhas que começam com o símbolo de hash # e, portanto, usamos o símbolo de hash para escrever comentários para explicar os passos em um programa. Veja os exemplos abaixo.

# x=-1 this is the first comment
spam = 1  # and this is the second comment
          # ... and now a third!

Funções Lambda#

Funções Lambda são pequenas funções anônimas criadas com a palavra-chave lambda:

nome_da_funcao = lambda parametro: valor_de_retorno

A expressão do lado direito do operador de atribuição = é uma função lambda anônima e nós a atribuímos ao nome de variável nome_da_funcao. As funções Lambda são úteis de pelo menos duas maneiras:

  • Definir uma função curta em uma única linha de código

  • Definir uma função dentro de alguma outra expressão Python

Por exemplo, a função de média definida acima pode ser escrita em uma única linha concisa:

average = lambda x: sum(x)/len(x)

A palavra-chave lambda indica que o que se segue é uma definição de função. O nome da variável x antes dos dois pontos é o parâmetro de entrada e a expressão após os dois pontos é o valor de retorno. Vamos verificar se nossa função lambda retorna os valores corretos:

average([1,2,3,4])

average([1,2,1,2])

custo = lambda x: 1+2*x
custo(3)

Crie funções lambda com vários parâmetros de entrada listando nomes de variáveis separados por vírgulas. Por exemplo, vamos criar uma função chamada hipotenusa que recebe os parâmetros de entrada x e y e retorna o comprimento da hipotenusa do triângulo retângulo com lados x e y.

hypotenuse = lambda x,y: (x**2 + y**2)**0.5

Verifique se nossa função retorna os valores corretos:

hypotenuse(3,4)

hypotenuse(5,12)

hypotenusep = lambda x,y,p=2: (x**p + y**p)**(1/p)

hypotenusep(3,4,p=3)

Função Zeta de Riemann#

A função zeta de Riemann é a soma infinita

\[ \zeta(s) = \sum_{n = 1}^{\infty} \frac{1}{n^s} \]

Escreva uma função chamada zeta que receba 2 parâmetros de entrada s e N e retorne a soma parcial:

\[ \sum_{n=1}^N \frac{1}{n^s} \]
def zeta(s,N):
    "Compute the Nth partial sum of the zeta function at s."
    terms = [1/n**s for n in range(1,N+1)]
    partial_sum = sum(terms)
    return partial_sum

Vamos testar nossa função com valores de entrada para os quais conhecemos o resultado:

zeta(1,1)

zeta(2,2)
1+(1/2)**2

Agora vamos usar nossa função para aproximar valores especiais da função zeta de Riemann:

\[ \zeta(2) = \frac{\pi^2}{6} \hspace{10mm} \text{e} \hspace{10mm} \zeta(4) = \frac{\pi^4}{90} \]

Calcule a soma parcial para \(s=2\) e \(N=100000\):

zeta(2,100000)

Compare com uma aproximação do valor especial \(\pi^2/6\):

Média Harmônica#

Escreva uma função chamada harmonic_mean que receba um parâmetro de entrada s, uma lista de números \(x_1, \dots, x_n\) de comprimento \(n\), e retorne a média harmônica da sequência:

\[ \frac{n}{\frac{1}{x_1} + \frac{1}{x_2} + \cdots + \frac{1}{x_n}} \]
def harmonic_mean(s):
    "Compute the harmonic mean of the numbers in the sequence s."
    n = len(s)
    terms = [1/s[i] for i in range(0,n)]
    result = n/sum(terms)
    return result

def aritmetic_mean(s):
    "Compute the aritmetic mean of the numbers in the sequence s."
    return sum(s)/len(s)

Vamos definir a média geométrica usando uma propriedade de logaritmo para reduzir um produtório em somatório: se \(a=x_1 ... x_n\), então

\[a=e^{(ln\, x_1 + ln\, x_2+...+ ln\, x_n)}\]

Logo, se \(s=(x_1, ..., x_n)\), então a média geométrica de \(s\) é:

\[ (x_1 ... x_n)^{(1/n)} = e^{\dfrac{ln\, x_1 + ln\, x_2+...+ ln\, x_n}{n}} \]
import math
def geometric_mean(s):
    "Compute the geometric mean of the numbers in the sequence s."
    n = len(s)
    # math.log(x) calcula o logaritmo natural de x
    terms = [math.log(s[i]) for i in range(0,n)]
    # math.exp(x) calcula e^x
    result = math.exp(sum(terms)/n)
    return result

def geometric_mean2(s):
    "Compute the geometric mean of the numbers in the sequence s."
    n = len(s)
    # math.prod(s) retorna o produto dos elementos de s
    result = math.prod(s)**(1/n)
    return result

Vamos testar nossa função:

harmonic_mean([1,1,1,1])

harmonic_mean([1,2,3])

aritmetic_mean([1,2,3])

geometric_mean([4,9])

geometric_mean([1,2,3])

geometric_mean2([1,2,3])

Somas de Riemann#

Escreva uma função chamada mn_integral que receba os parâmetros de entrada m, n, a, b e N e retorne a soma de Riemann à direita: $\( \int_a^b f(x) \, dx \approx \sum_{k=1}^N f(x_k) \Delta x \ \ , \ \ f(x) = \frac{x^m + 1}{x^n + 1} \)$

e \(\Delta x = (b-a)/N\) e \(x_k = a + k \Delta x\).

a=0
b=1
N=10
delta_x = (b - a)/N
x = [a + k*delta_x for k in range(0,N+1)]

print(x[1])

def mn_integral(m,n,a,b,N):
    '''Compute the right Riemann sum for the function f(x) = (x^m + 1)/(x^n + 1)
    on interval [a,b] with a partition of N subintervals of equal size.
    '''
    delta_x = (b - a)/N
    # lista de valores x_k:
    x = [a + k*delta_x for k in range(0,N+1)]
    # lista de valores f(x_k)\Delta_x:
    terms = [(x[k]**m + 1)/(x[k]**n + 1)*delta_x for k in range(1,N+1)]
    riemann_sum = sum(terms)
    return riemann_sum

Vamos testar nossa função com uma entrada para a qual conhecemos o resultado. Seja \(m=0\), \(n=1\), \(a=0\), \(b=1\) e \(N=2\). Então \(x_0 = 0\), \(x_1 = 1/2\), \(x_2 = 1\) e \(\Delta x = 1/2\), e calculamos:

\[\begin{split} \begin{aligned} \sum_{k=1}^N f(x_k) \Delta x &= \sum_{k=1}^2 \frac{x_k^0 + 1}{x_k^1 + 1} \Delta x \\\ &= \frac{2}{(1/2) + 1} \cdot \frac{1}{2} + \frac{2}{1 + 1} \cdot \frac{1}{2} \\\ &= \frac{7}{6} \end{aligned} \end{split}\]
mn_integral(0,1,0,1,2)

7/6

Vamos testar nossa função em outro exemplo. Seja \(m=1\), \(n=2\), \(a=0\) e \(b=1\). Podemos resolver esta integral exatamente:

\[\begin{split} \begin{aligned} \int_0^1 \frac{x + 1}{x^2 + 1} dx &= \int_0^1 \frac{x}{x^2 + 1} dx + \int_0^1 \frac{1}{x^2 + 1} dx \\\ &= \left. \left( \frac{1}{2} \ln(x^2 + 1) + \arctan x \right) \right|_0^1 \\\ &= \frac{1}{2} \ln(2) + \frac{\pi}{4} \end{aligned} \end{split}\]

Aproxime esta integral com uma soma de Riemann para \(N=100000\):

mn_integral(1,2,0,1,100000)

Como \(\pi \approx 3.14159265\) e \(\ln(2) \approx 0.69314718\), comparamos com a aproximação:

0.5*math.log(2) + math.pi/4

Nossa função calcula os valores esperados!

Exercícios#

Exercício 1. Escreva uma função chamada p_norm que receba os parâmetros de entrada sequencia e p, onde sequencia é uma lista de números \(x_1, \dots, x_n\) e p é um número diferente de zero. A função retorna a \(p\)-norma:

\[ \left( \frac{1}{n} \sum_{i=1}^n | x_i |^p \right)^{1/p} \]

Use valores positivos grandes de p e várias listas de números para verificar que

\[ \lim_{p \to \infty} \left( \frac{1}{n} \sum_{i=1}^n | x_i |^p \right)^{1/p} = \max \{ |x_1| , \dots, |x_n| \} \]

Use valores negativos grandes de p e várias listas de números para verificar que

\[ \lim_{p \to -\infty} \left( \frac{1}{n} \sum_{i=1}^n |x_i|^p \right)^{1/p} = \min \{ |x_1| , \dots, |x_n| \} \]

Exercício 2. Escreva uma função chamada arctan_taylor que receba os parâmetros de entrada x e N e retorne o polinômio de Taylor de grau \(N\) da função \(\arctan x\) avaliado em x:

\[ \sum_{k=0}^N (-1)^k \frac{x^{2k + 1}}{2k + 1} \]

Exercício 3. Escreva uma função chamada zips que receba os parâmetros de entrada a e b, onde a e b são listas de igual comprimento, e retorne a lista de tuplas que agrega a sequência. (Em outras palavras, escreva sua própria versão da função embutida zip()… sem usar zip(), é claro.) Por exemplo, zips([-1,3,4,0],[5,7,1,-9]) retorna a lista [(-1, 5), (3, 7), (4, 1), (0, -9)].

Exercício 4. Escreva uma função chamada sqrt_integral que receba os parâmetros de entrada u, p e N e retorne a soma de Riemann (usando os pontos médios \(x_k^*\) de uma partição de tamanho \(N\)):

\[ \int_0^u \frac{1}{\sqrt{1 + x^p}} dx \approx \sum_{k=1}^N \frac{1}{\sqrt{1 + (x_k^*)^p}} \Delta x \]

onde \(\Delta x = u/N\) e \(x_k^* = (x_k + x_{k-1})/2\) para os pontos finais \(x_k = k \Delta x\).
