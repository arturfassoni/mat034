Problema 1: Análise da Distribuição de Números Primos#

Números primos são a base de muitos algoritmos em ciência da computação e criptografia. A forma como eles se distribuem na reta numérica é um tópico de intenso estudo. Nesta questão, você irá implementar um método eficiente para encontrar primos e visualizar a distribuição dos «espaços» entre eles.

Tarefas:

  1. Crivo de Eratóstenes com NumPy: Escreva uma função crivo_numpy(n) que receba um inteiro n e retorne um array NumPy com todos os números primos até n. Utilize a técnica do Crivo de Eratóstenes com arrays booleanos do NumPy para uma implementação eficiente (evite usar loops for para marcar os múltiplos).

  2. Geração e Cálculo dos Espaços: Use sua função para gerar todos os primos até 50.000. Em seguida, crie um novo array contendo as diferenças (os «espaços») entre cada primo consecutivo. Por exemplo, para os primos [2, 3, 5, 7], os espaços são [1, 2, 2]. (Dica: a função np.diff() pode ser útil aqui).

  3. Visualização: Crie um histograma com matplotlib.pyplot.hist() para visualizar a distribuição desses espaços. Use pelo menos 30 barras (bins=30). Adicione um título e rótulos aos eixos x (Tamanho do Espaço) e y (Frequência).

  4. Análise (em uma célula de Markdown): Com base no seu histograma, qual é o espaço mais comum entre números primos consecutivos na sua amostra? O que você observa sobre a frequência de espaços maiores?

Problema 2: Simulação e Análise de um Passeio Aleatório 2D#

O passeio aleatório (random walk) é um modelo matemático usado para descrever uma ampla gama de fenômenos, desde o movimento de uma molécula em um gás até as flutuações de preços no mercado de ações.

Tarefas:

  1. Geração do Passeio: Crie uma função passeio_aleatorio_2d(passos) que simule um passeio aleatório de passos etapas em um plano 2D.

    • Comece na origem (0,0).

    • Para cada passo, escolha aleatoriamente uma de quatro direções: para cima (+1 em y), para baixo (-1 em y), para a direita (+1 em x) ou para a esquerda (-1 em x).

    • A função deve retornar duas arrays NumPy, x e y, contendo as coordenadas em cada etapa do percurso. (Dica: np.random.choice e np.cumsum são muito úteis).

  2. Simulação e Plotagem: Gere um passeio aleatório com 2.000 passos.

    • Plote a trajetória completa do passeio (gráfico de y versus x).

    • Marque o ponto inicial (0,0) com um marcador verde grande.

    • Marque o ponto final com um marcador vermelho grande.

  3. Análise da Distância: Calcule a distância Euclidiana final do ponto de partida, definida como \(\sqrt{x_{final}^2 + y_{final}^2}\).

  4. Visualização Avançada: No mesmo gráfico, use plt.scatter() para marcar todos os pontos do percurso onde o passeio esteve a uma distância maior que 20 da origem. Use uma cor diferente para esses pontos.

Problema 3: Visualização do Conjunto de Mandelbrot#

O Conjunto de Mandelbrot é um dos fractais mais famosos da matemática. Sua beleza reside em uma estrutura infinitamente complexa gerada por uma regra muito simples. Um ponto c no plano complexo pertence ao conjunto se a sequência definida por \(z_{n+1} = z_n^2 + c\), com \(z_0 = 0\), permanece limitada (ou seja, \(|z_n| \leq 2\)).

Tarefas:

  1. Criação da Grade: Usando np.linspace e np.meshgrid, crie uma grade de números complexos c. O eixo real deve ir de -2 a 1, e o eixo imaginário de -1.5 a 1.5. Use uma resolução de 800x600 pontos (largura x altura).

  2. Função de Iteração Vetorizada: Escreva uma função mandelbrot(c, max_iter) que receba a matriz de números complexos c e um número máximo de iterações max_iter. A função deve:

    • Inicializar uma matriz z de zeros com a mesma forma de c.

    • Inicializar uma matriz divergencia de inteiros (com max_iter em todas as posições) para armazenar em qual iteração cada ponto divergiu.

    • Iterar max_iter vezes. Em cada iteração, para os pontos que ainda não divergiram (\(|z| \leq 2\)):

      • Atualize z pela fórmula \(z = z^2 + c\).

      • Verifique quais novos pontos ultrapassaram o limite de 2. Para esses pontos, armazene o número da iteração atual na matriz divergencia e marque-os para não serem mais atualizados. (Dica: use indexação booleana do NumPy para fazer isso de forma vetorizada, sem loops for sobre os pixels).

  3. Visualização: Chame sua função com max_iter = 50. Use plt.imshow() para visualizar a matriz divergencia. Use um mapa de cores como 'plasma' ou 'inferno'. Adicione um título e remova os eixos (plt.axis('off')) para uma melhor visualização.

Problema 4: Aproximação de uma Onda Triangular por Série de Fourier#

Qualquer função periódica pode ser aproximada por uma soma de senos e cossenos, conhecida como Série de Fourier. A série para uma onda triangular com amplitude 1 e período \(2\pi\) é:

\[f(t) = \frac{8}{\pi^2} \sum_{k=1, 3, 5, ...}^{\infty} \frac{(-1)^{(k-1)/2}}{k^2} \sin(k t)\]

Note que a soma é apenas sobre os inteiros ímpares \(k\).

Tarefas:

  1. Função de Aproximação: Crie uma função fourier_triangular(t, N) que receba um array de tempo t e um inteiro N (o número de termos na soma) e retorne a aproximação da onda triangular. A sua função deve somar os N primeiros termos da série (ou seja, para \(k = 1, 3, 5, ..., 2N-1\)).

  2. Criação dos Gráficos: Use plt.subplots(2, 2, ...) para criar uma grade de 4 gráficos.

  3. Plotagem e Comparação:

    • Em cada um dos 4 subplots, plote a onda triangular «ideal» (você pode criá-la manualmente ou com scipy.signal.sawtooth com o argumento width=0.5). Plote-a no intervalo de \(t = -2\pi\) a \(2\pi\).

    • No primeiro subplot, sobreponha a aproximação de Fourier com N=1.

    • No segundo, sobreponha com N=3.

    • No terceiro, com N=5.

    • No quarto, com N=50.

  4. Formatação: Dê a cada subplot um título indicando o número de termos (ex: «N=5 Termos»). Adicione um título geral à figura. Use plt.tight_layout() para ajustar o espaçamento.

Problema 5: Análise de Órbita Planetária#

A órbita de um planeta em torno de sua estrela pode ser descrita por uma elipse. A distância do planeta à estrela, \(r\), em função do ângulo \(\theta\) (anomalia verdadeira) é dada por:

\[r(\theta) = \frac{a(1 - e^2)}{1 + e \cos(\theta)}\]

onde \(a\) é o semieixo maior e \(e\) é a excentricidade da órbita.

Vamos analisar a órbita de um planeta hipotético com \(a = 2.5\) UA (Unidades Astronômicas) e \(e = 0.8\) (uma elipse bem «achatada»).

Tarefas:

  1. Cálculo da Trajetória: Crie um array theta de \(0\) a \(2\pi\) com 400 pontos. Calcule a distância r para cada theta.

  2. Visualização em Coordenadas Polares: Matplotlib pode criar gráficos polares.

    • Crie um subplot usando plt.subplot(projection='polar').

    • Plote a órbita usando ax.plot(theta, r).

    • A estrela está em um dos focos, que na origem deste sistema de coordenadas.

  3. Cálculo da Velocidade (Aproximação): A velocidade de um corpo em órbita não é constante. Ela é máxima no periélio (ponto mais próximo) e mínima no afélio (ponto mais afastado). Uma aproximação para a magnitude da velocidade é a taxa de variação da distância em relação ao tempo. Se assumirmos que a velocidade angular é aproximadamente constante, podemos aproximar a velocidade radial como a derivada da distância em relação ao ângulo, \(|dr/d\theta|\).

    • Use diferenciação numérica (sua função derivative ou scipy.misc.derivative) para calcular \(dr/d\theta\) para cada ponto da órbita.

    • Encontre a velocidade radial máxima e mínima.

  4. Análise e Anotação no Gráfico:

    • Encontre os ângulos \(\theta\) onde a distância r é mínima (periélio) e máxima (afélio) usando np.argmin e np.argmax.

    • No seu gráfico polar, use ax.plot() para marcar os pontos do periélio e afélio com marcadores distintos (ex: um “x” vermelho e um “o” azul).

    • Adicione uma legenda para explicar os pontos.

Problema 6: Otimização e Geometria – O Cone de Volume Máximo#

Imagine que você tem uma folha de papel circular de raio \(R\). Você corta uma fatia (um setor circular) com um ângulo \(\theta\) (em radianos) e une as bordas para formar um cone. O objetivo é encontrar o ângulo \(\theta\) que deve ser removido para que o cone resultante tenha o volume máximo possível.

Fórmulas úteis:

  • O raio da base do cone, \(r\), e a altura, \(h\), podem ser expressos em termos de \(R\) e \(\theta\). O comprimento do arco da porção restante do círculo, \(R(2\pi - \theta)\), torna-se a circunferência da base do cone, \(2\pi r\). A geratriz do cone é \(R\).

  • Volume do cone: \(V = \frac{1}{3}\pi r^2 h\).

Tarefas:

  1. Modelagem: Usando as relações acima, mostre que o volume do cone pode ser escrito como uma função de uma única variável, por exemplo, o raio da base \(r\): \(V(r) = \frac{1}{3}\pi r^2 \sqrt{R^2 - r^2}\).

  2. Otimização: Para maximizar o volume, precisamos encontrar a raiz da derivada \(V'(r) = 0\). Calcule a derivada de \(V(r)\) em relação a \(r\) analiticamente. (Dica: para simplificar, você pode maximizar \(V^2(r)\) em vez de \(V(r)\)).

  3. Busca da Raiz: A equação \(V'(r) = 0\) não é trivial de resolver. Use o método de Newton para encontrar o valor de \(r\) que maximiza o volume. Assuma \(R=10\) cm e use uma estimativa inicial, \(x_0\), apropriada (por exemplo, \(x_0 = 8\)).

  4. Cálculo Final: Com o valor ótimo de \(r\) encontrado, calcule:

    a) A altura \(h\) correspondente.

    b) O ângulo \(\theta\) (em graus) que deve ser removido.

    c) O volume máximo do cone.

Problema 7: Intersecção de Curvas e Análise de Taxa de Variação#

Queremos encontrar o ponto de intersecção entre a curva de um oscilador amortecido, \(f(x) = e^{-x/2} \cos(2\pi x)\), e uma curva de decaimento exponencial simples, \(g(x) = 1.5e^{-x}\), para \(x \geq 1\).

Tarefas:

  1. Visualização: Plote ambas as funções, \(f(x)\) e \(g(x)\), no mesmo gráfico no intervalo \([0, 2]\). Isso ajudará a visualizar o ponto de intersecção e a escolher um bom intervalo inicial para a busca de raiz.

  2. Encontrando a Intersecção: A intersecção ocorre quando \(f(x) = g(x)\), ou seja, quando \(H(x) = f(x) - g(x) = 0\). Use o método da secante para encontrar a coordenada \(x\) deste ponto de intersecção com uma precisão de \(10^{-7}\). Use o gráfico da etapa 1 para definir seu intervalo inicial \([a, b]\).

  3. Análise da Derivada: No ponto de intersecção encontrado, qual das duas curvas está decaindo mais rapidamente? Para responder a isso, calcule as derivadas \(f'(x)\) e \(g'(x)\) nesse ponto usando diferenciação numérica (com a sua função derivative ou scipy.misc.derivative).

  4. Apresentação: Imprima a coordenada \((x, y)\) da intersecção e os valores das derivadas de ambas as funções nesse ponto, explicando sua conclusão.

Problema 8: Cálculo do Centro de Massa de uma Placa com Densidade Variável#

O centro de massa \((\bar{x}, \bar{y})\) de uma placa (lâmina) plana que ocupa uma região \(D\) com uma função de densidade \(\rho(x, y)\) é dado por:

\[\bar{x} = \frac{M_y}{M} \quad , \quad \bar{y} = \frac{M_x}{M}\]

onde:

  • Massa total: \(M = \iint_D \rho(x, y) \,dA\)

  • Momento em relação ao eixo y: \(M_y = \iint_D x \rho(x, y) \,dA\)

  • Momento em relação ao eixo x: \(M_x = \iint_D y \rho(x, y) \,dA\)

Considere uma placa semicircular definida por \(x^2 + y^2 \leq 4\) com \(y \geq 0\). A densidade da placa não é uniforme e varia com a distância ao eixo y, sendo dada por \(\rho(x, y) = 1 + 0.5x^2\).

Tarefas:

  1. Configuração das Integrais: Converta as integrais duplas acima em integrais iteradas. Por simetria, você pode deduzir que \(\bar{x} = 0\). Você precisará configurar as integrais para a massa \(M\) e o momento \(M_x\):

    \[M = \int_{-2}^{2} \int_{0}^{\sqrt{4-x^2}} (1 + 0.5x^2) \,dy\,dx\]
    \[M_x = \int_{-2}^{2} \int_{0}^{\sqrt{4-x^2}} y(1 + 0.5x^2) \,dy\,dx\]

  2. Simplificação: Resolva as integrais internas (em relação a \(y\)) analiticamente. Isso resultará em duas integrais simples (em relação a \(x\)).

  3. Cálculo Numérico: Use a regra de Simpson (simps ou scipy.integrate.simps) com N=200 para calcular os valores numéricos das duas integrais resultantes da etapa 2.

  4. Resultado Final: Calcule e apresente a coordenada \(\bar{y}\) do centro de massa.

Problema 9: O Problema da Braquistócrona e o Tempo de Queda#

A braquistócrona é a curva entre dois pontos que um objeto em queda livre (sem atrito, sob gravidade constante) percorre no menor tempo possível. Essa curva não é uma reta, mas sim uma cicloide.

As equações paramétricas de uma cicloide (com \(r=1\)) que passa pela origem são:

\[x(\theta) = r(\theta - \sin\theta), \quad y(\theta) = r(1 - \cos\theta). \]

O tempo de descida ao longo de uma curva \((x(\theta), y(\theta))\) de \(\theta_A\) até \(\theta_B\) é:

\[T = \int_{\theta_A}^{\theta_B} \frac{\sqrt{x'(\theta)^2 + y'(\theta)^2}}{\sqrt{2gy(\theta)}} d\theta\]

Tarefas:

  1. Cálculo das Derivadas: Calcule as derivadas \(x'(\theta)\) e \(y'(\theta)\) analiticamente.

  2. Função do Integrando: Calcule a função do integrando \(f(\theta) = \frac{\sqrt{x'(\theta)^2 + y'(\theta)^2}}{\sqrt{2gy(\theta)}}\) analiticamente e então a defina como uma função em Python. Assuma \(r=1\) e \(g=9.81\).

  3. Tempo na Cicloide: Calcule numericamente o tempo de descida ao longo da cicloide desde o ponto A (origem, \(\theta_A = 0\)) até o ponto B (\(x \approx 5.14\), \(y \approx 1.27\), que corresponde a \(\theta_B = 2.5\) radianos). Use uma técnica de integração numérica de sua escolha (por exemplo, scipy.integrate.quad ou sua função simps com N grande).

  4. Comparação: Calcule o tempo de descida para um objeto que cai ao longo de uma rampa reta entre os mesmos pontos A e B. A fórmula para o tempo em uma rampa reta de comprimento \(L\) e inclinação \(\alpha\) é \(T_{reta} = \sqrt{2L / (g \sin\alpha)}\).

  5. Conclusão (em uma célula Markdown): Compare os dois tempos. Seu resultado confirma que a cicloide é a trajetória mais rápida?

Problema 10: Análise do Potencial de Lennard-Jones#

O potencial de Lennard-Jones é um modelo matemático que descreve a energia potencial \(V\) da interação entre duas partículas neutras em função da distância \(r\) entre elas:

\[V(r) = 4\epsilon \left[ \left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^{6} \right]\]

A força entre as partículas é \(F(r) = -V'(r)\). Uma posição de equilíbrio estável ocorre no ponto \(r_0\) onde a energia potencial é mínima, ou seja, onde a força é nula, \(F(r_0) = -V'(r_0) = 0\).

Para esta questão, use os parâmetros para o Argônio: \(\sigma = 3.4 \times 10^{-10}\) m e \(\epsilon = 1.65 \times 10^{-21}\) J.

Tarefas:

  1. Força e Equilíbrio:

    a) Calcule a primeira derivada \(V'(r)\) analiticamente para obter a fórmula da força \(F(r)\).

    b) Use um método de busca de raiz de sua escolha para encontrar a distância de equilíbrio \(r_0\) onde \(F(r_0)=0\). Use uma tolerância de \(10^{-12}\).

  2. Visualização: Plote o potencial \(V(r)\) em função de \(r\) (para \(r\) de \(3 \times 10^{-10}\) a \(8 \times 10^{-10}\) m). Marque no gráfico o ponto de mínimo \((r_0, V(r_0))\) que você encontrou.

  3. Frequência de Oscilação: Para pequenas oscilações em torno do ponto de equilíbrio, o sistema se comporta como um oscilador harmônico com uma «constante de mola» \(k = V''(r_0)\).

    a) Use diferenciação numérica para calcular a segunda derivada \(V''(x)\) no ponto de equilíbrio \(r_0\) para encontrar a constante \(k\).

    b) A frequência angular de oscilação é \(\omega = \sqrt{k/\mu}\), onde \(\mu\) é a massa reduzida. Para duas partículas de Argônio, \(\mu \approx 3.32 \times 10^{-26}\) kg. Calcule a frequência angular \(\omega\).

  4. Relatório Final: Apresente a distância de equilíbrio \(r_0\), a energia potencial mínima \(V(r_0)\), a constante de mola efetiva \(k\) e a frequência de oscilação \(\omega\).
