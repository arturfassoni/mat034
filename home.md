# Matemática Computacional

Bem-vindo às notas de aula da disciplina **MAT034 - Matemática Computacional**, ministrada pelo [Prof. Artur Fassoni](https://arturfassoni.github.io), a alunos do curso Matemática Bacharelado, na Universidade Federal de Itajubá, no segundo semestre de 2026.

## Objetivo

O objetivo destas notas de aula é capacitar o aluno a implementar métodos numéricos clássicos utilizando a linguagem Python, resolvendo problemas matemáticos, modelando fenômenos e analisando os resultados de forma crítica.

Estas notas contêm seções de autoaprendizagem de Python, seções de revisão de conceitos teóricos dos métodos numéricos, implementações destes em Python e exercícios e problemas propostos.

## Conteúdo
- Introdução à linguagem Python para computação científica e visualização de dados
- Implementação de métodos numéricos para zeros de funções e integração numérica.
- Resolução numérica de equações diferenciais ordinárias.
- Aplicações da Álgebra Linear.

## Pré-requisitos
- Cálculo Diferencial e Integral
- Equações Diferenciais
- Cálculo Numérico
